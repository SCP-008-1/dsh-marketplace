📦 基于 GitHub Topic 的全自动收录机制

dsh 插件生态基于 GitHub Topic 自动发现，无需注册独立账号或提交表单。仅需 3 步即可完成收录发布：

1
创建公开的 GitHub 代码仓库
包含清晰的 README.md 使用说明、开源许可证（License）和插件入口代码。
2
添加核心 Topic 标签
在仓库首页右侧的「About → Topics」设置中添加必备标签：
🏷️ dsh-plugin（点击复制）
3
添加分类与场景标签（可选）
为插件添加类型标签，方便开发者在商城中按分类筛选发现：
dsh-mcp dsh-skill dsh-theme dsh-prompt

⏱️ 每小时全自动定时同步

GitHub Actions 爬虫每 1 小时自动运行一次，严格校验 NPM 包与 GitHub 仓库双向归属，并同步更新 Web 插件商城与 GitHub Wiki 文档。
