发布与收录 dsh 插件

📦 自动发现与严格收录机制

dsh 采用基于 GitHub Topics 的开放收录标准。无需人工提交审核或注册账号，只需 3 步即可被全网收录：

1
创建公开 GitHub 仓库
包含完善的 README.md 描述及插件主程序。
2
添加核心 Topic 标签
在仓库主页右侧 "About -> Topics" 中添加：
🏷️ dsh-plugin (点击快速复制)
3
细分类型标签（可选）
按功能追加分类标签，便于精准筛选与展示：
dsh-skill dsh-mcp dsh-theme dsh-prompt

⏱️ 自动化同步与双向校验

GitHub Actions 机器人每 1 小时自动扫描全网公开仓库，严格双向校验 NPM 注册状态并同步至本商城与 GitHub Wiki。
