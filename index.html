发布与收录 dsh 插件

📦 自动发现机制

dsh 采用基于 GitHub Topics 的开放收录标准。无需人工提交 PR 或注册账号，只需 3 步即可全网收录：

1
创建公开 GitHub 仓库
包含完善的 README.md 描述及插件主程序。
2
添加核心 Topic 标签
在仓库主页右侧 "About -> Topics" 中添加：
🏷️ dsh-plugin (点击复制)
3
细分类型标签（可选）
按功能追加分类标签，便于精准筛选：
dsh-skill dsh-mcp dsh-theme dsh-prompt

⏱️ 自动化同步

GitHub Actions 机器人每 1 小时自动扫描全网公开仓库，同步索引至本商城与 GitHub Wiki。
